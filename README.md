<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/favicon/favicon.ico" width="35"/> Crikly</h1>

<p align="center">
  Crikly is an interactive web application that visualizes IPL 2024 performance data, featuring charts to track the tournament’s top run-scorers and leading wicket-takers.
</p>

![CriklyDemo](https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/demos/CriklyDemo.png)

<img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature | Description |
| ------- | ----------- |
| 📈 **Interactive Charts** | Visualize player stats using dynamic charts |
| 🏆 **Top Batsmen** | View the highest run-scorers of IPL 2024 |
| 🎳 **Top Bowlers** | Analyze the leading wicket-takers |
| ✨ **Clean UI** | Minimal and easy-to-understand interface |
| 💻 **Web-Based** | Runs directly in the browser |
