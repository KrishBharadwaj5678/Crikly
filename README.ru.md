<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/favicon/favicon.ico" width="35"/> Crikly</h1>

<p align="center">
  Crikly это интерактивное веб-приложение для визуализации статистики IPL 2024 с помощью динамических диаграмм, позволяющих отслеживать лучших бомбардиров и лидеров по количеству взятых калиток.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ----------- | -------- |
| 📈 **Интерактивные диаграммы** | Визуализация статистики игроков с помощью динамических диаграмм |
| 🏆 **Лучшие бэтсмены** | Просмотр игроков с наибольшим количеством набранных ранов в IPL 2024 |
| 🎳 **Лучшие боулеры** | Анализ лидеров по количеству взятых калиток |
| ✨ **Чистый интерфейс** | Минималистичный и понятный пользовательский интерфейс |
| 💻 **Веб-приложение** | Работает непосредственно в браузере |
