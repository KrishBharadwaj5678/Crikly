<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/favicon/favicon.ico" width="35"/> Crikly</h1>

<p align="center">
  Criklyは、IPL 2024のパフォーマンスデータを視覚化するインタラクティブなWebアプリケーションです。チャートを使用して、大会の最多得点者と最多ウィケット獲得者を追跡できます。
</p>

![CriklyDemo](https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/demos/CriklyDemo.png)

<img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| 📈 **インタラクティブチャート** | 動的なチャートで選手の統計データを視覚化 |
| 🏆 **トップバッター** | IPL 2024の最多得点者を表示 |
| 🎳 **トップボウラー** | ウィケット獲得数の上位選手を分析 |
| ✨ **シンプルなUI** | ミニマルで分かりやすいユーザーインターフェース |
| 💻 **Webベース** | ブラウザ上で直接実行可能 |

## <img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

```bash
git clone https://github.com/KrishBharadwaj5678/Crikly.git
```

### 2️⃣ プロジェクトへ移動

```bash
cd Crikly
```

### 3️⃣ ブラウザで開く

index.html ファイルをブラウザで開くだけで実行できます。
