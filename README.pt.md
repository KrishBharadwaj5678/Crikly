<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/favicon/favicon.ico" width="35"/> Crikly</h1>

<p align="center">
  Crikly é uma aplicação web interativa que visualiza dados de desempenho da IPL 2024, apresentando gráficos para acompanhar os maiores pontuadores e os principais jogadores em número de wickets conquistados no torneio.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Crikly/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| -------------- | --------- |
| 📈 **Gráficos Interativos** | Visualize estatísticas dos jogadores por meio de gráficos dinâmicos |
| 🏆 **Principais Batedores** | Veja os jogadores com mais corridas na IPL 2024 |
| 🎳 **Principais Arremessadores** | Analise os jogadores com maior número de wickets |
| ✨ **Interface Limpa** | Interface minimalista e fácil de entender |
| 💻 **Baseado na Web** | Funciona diretamente no navegador |
